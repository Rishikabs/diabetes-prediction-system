# Diabetes Prediction System

## Project Overview

The Diabetes Prediction System is a machine learning-based web application that predicts whether a person is likely to have diabetes based on medical input parameters. The project uses a trained machine learning model with a Flask web interface to provide fast and accurate predictions.

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Docker
- Kubernetes

## Features

- Diabetes Prediction using Machine Learning
- User-Friendly Web Interface
- Dataset Preprocessing
- Model Training and Evaluation
- Docker Containerization
- Kubernetes Deployment
- Report Generation

## Installation

1. Clone the repository.

```bash
git clone https://github.com/<your-username>/diabetes-prediction-system.git
```

2. Install dependencies.

```bash
pip install -r requirements.txt
```

3. Run the application.

```bash
python app.py
```
